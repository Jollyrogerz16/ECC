# Suno Style Vocabulary

Use these as *axes*, not as a dump into one prompt. Pick one value per axis. Full prompting rules live in `SKILL.md`.

## Genre → subgenre

| Primary | Useful subgenres |
|---|---|
| Alt-R&B | late-night, penthouse, dusty, experimental |
| Pop | synth-pop, alt-pop, dance-pop, bedroom |
| Hyperpop | glitch, neon, nightcore-adjacent, PC-music sheen |
| Indie | bedroom, folk, noise-pop, slacker |
| Electronic | house, techno, UKG, ambient, jungle |
| Rock | indie, shoegaze, post-punk, heartland |
| Hip-hop | boom-bap, trap, drill, abstract |
| Country | alt-country, folk-country, 90s radio (era, not clone) |
| Metal | djent-adjacent, blackgaze, industrial |
| Soundtrack | trailer, pulse, analog-score — avoid "epic orchestra" unless that is the brief |

## Vocal character (write 3–5 words)

- intimate dry chest voice
- airy falsetto with cracks
- spoken-sung baritone
- stacked gang vocals
- smoky mezzo, close mic
- clipped rhythmic rap-sung
- choir (only if you actually want it)

## Drums / groove

- dry close-mic kit
- swung hats, lazy snare
- four-on-the-floor, side-chained
- brushed snare, no crash
- 808 + sparse hats
- live room kit, long decay (harder to split)

## Space

- dry / no reverb
- short room
- plate on vocal only
- hall (use sparingly)
- tape slap
- club system, mono-ish low end

## Mix era

- modern streaming
- 70s analog
- 80s gated
- 90s radio
- dusty sampler / lo-fi (exclude if you do not want it)

## Exclude presets

Common accidental additions:

```text
choir, gospel, opera, children's choir, cinematic strings,
EDM drop, dubstep, chiptune, lo-fi hop, spoken word, talkbox
```

Write only the ones this brief keeps tripping over.
